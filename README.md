# Are Songs Getting Shorter?  
### A Spotify Data Deep Dive (2009–2025)

This project explores how song duration relates to popularity in the streaming era using Spotify data from 2009–2025.  
I focus on questions like:

- Are songs actually getting shorter over time?
- Is there a “sweet spot” for song length that maximizes popularity?
- Has the streaming + TikTok era pushed artists toward 3–4 minute tracks?

The analysis uses two main datasets:
- **Classic tracks (2009–2023)** from Spotify global charts  
- **Modern tracks (2025)** from recent Spotify releases  

All cleaning, visualization, and analysis are done in Python.
